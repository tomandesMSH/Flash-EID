# EID for The Binding of Isaac (Flash)

An External Item Descriptions overlay for the original Flash game
([Steam app 113200](https://store.steampowered.com/app/113200/The_Binding_of_Isaac/), including Wrath of the Lamb
and the Eternal Edition). It shows the description of the nearest item pedestal, trinket, card or pill (on the floor or
in a shop), rendered the same way [External Item Descriptions](https://github.com/wofsauge/External-Item-Descriptions)
renders it: EID's bitmap font, inline icons, bullet points, item type/charge icons and colors.

Players install it with the **patcher** (`patcher/`): it builds the modded game from their own copy, so no game files
are ever distributed. See `patcher/README.txt` for the player instructions.

Assets taken from EID: `resources/font/eid_default*` (bitmap font, from PixelMplus10), `resources/gfx/eid_inline_icons.*`,
`resources/gfx/eid_transform_icons.*` and the markup tables in `data/eid_markup.lua`.

## How it works

The Flash game has no mod API. The Steam build is an MDM Zinc 3 projector that keeps the game SWF encrypted inside
`Isaac.exe`.

- **Release side** (`tools/make_payload.py`): EID's code is compiled on its own into a DoAction tag (a generated
  one-frame SWF is filled by FFDec and the tag is taken out again). It is stored in
  `patcher/eid_flash_payload.json` together with the font/icon atlas. The payload contains only EID's own code and
  assets, no game code.
- **Player side** (`patcher/eid_flash_patcher.py`, Python standard library only):
  1. Copies the game folder to a temporary folder and runs the copy for a few seconds.
  2. Reads the decrypted SWF (SWF 8, ActionScript 2) from the copy's memory.
  3. Inserts the atlas (`DefineBitsLossless2` + `ExportAssets` "eid_atlas") and the EID DoAction into frame 1, after
     the game's own script.
  4. Writes `EID Flash/isaac_eid.swf` and the launcher `EID Flash/EID Flash.exe` for Adobe's standalone Flash Player
     32 projector (`--get-projector` downloads it and verifies its checksum).
  5. Prints the Steam launch option `"<folder>\EID Flash\EID Flash.exe" %command%` and copies it to the clipboard,
     for the player to paste into the game's Launch Options in Steam. Steam's files are never edited.

The patcher checks the SWF's SHA-256 against the tested game version and warns if it differs. The developer build
runs the same patcher on the same payload, so it is byte-for-byte what players get.

The overlay ports EID's `printDescription`, `printBulletPoints`, `renderString` and `fitTextToWidth`. It uses the
same 1x layout units (line height 11, textbox width 130, 12px bullet indent, 0.75 transparency) and draws the result
pixel for pixel at 2x scale.

## Layout

| Path | Purpose |
|---|---|
| `descriptions/en_us.lua` | Collectible, trinket, card and pill descriptions in EID's format and markup (`{"ID", "Name", "Description"}`). |
| `descriptions/item_data.lua` | Item type (passive/active/familiar) and charges; mappings from the game's internal card and pill values to EID's card and pill IDs. |
| `as2/eid_host.as` | Projector compatibility: replaces the game's Zinc-only fullscreen (`fullf`) and quit (`nooo`) with Flash Player equivalents (4:3 scaling, F key / Options toggle, saved setting). |
| `as2/eid_flash.as` | Overlay and renderer (ActionScript 2). |
| `as2/eid_debug.as` | Test-only hooks for `--debug` builds: F9 teleports to the treasure room, F8 cycles the pedestal item, F7 spawns test trinkets/cards/pills, F6 identifies pill color 1. |
| `patcher/eid_flash_patcher.py` | The player-facing patcher: dumps the user's game, applies the payload, sets up the launcher. |
| `patcher/eid_flash_payload.json` | Generated by `build.py`: compiled EID code + atlas. Contains no game code. |
| `patcher/README.txt` | Player instructions, shipped in the release zip. |
| `launcher/EIDFlashLauncher.cs` | `EID Flash.exe` (C#, compiled with Windows' .NET Framework `csc`): starts the projector with `isaac_eid.swf` from its own folder, ignores its arguments (Steam's `%command%` would otherwise be opened as the movie) and waits for the game to close so Steam counts playtime. |
| `tools/swfdump.py` | Developer helper: dumps `<work>/isaac.swf` with the patcher's dump code. |
| `tools/eid_assets.py` | Builds the atlas and AS2 tables from `resources/font/eid_default.fnt`, `resources/gfx/eid_inline_icons.anm2`, `resources/gfx/eid_transform_icons.anm2`, `data/eid_markup.lua` (`InlineIcons`, `InlineColors`, `TextReplacementPairs`) and `descriptions/`. |
| `data/eid_markup.lua` | EID's inline icon, color and text replacement tables (copied from EID's `features/eid_data.lua`). |
| `VERSION` | Version of the Flash edition (used in the payload and release zip name). |
| `tools/make_payload.py` | Compiles the EID AS2 code on its own and the launcher, and writes the payload. |
| `tools/build.py` | Developer build: makes the payload and applies it with the patcher. |
| `tools/package.py` | Zips `patcher/` into `EID_Flash_<version>.zip` for release. |
| `tools/build_exe.py` | Builds `EID_Flash_Patcher.exe` (PyInstaller, single file, payload bundled). |
| `tools/test/` | `keys.ps1` and `shot.ps1`: send keys to the game window and screenshot it, for automated in-game tests. |
| `tools/research/` | Scripts used to extract item names from the game and effect text from the wiki (items, trinkets, cards, pills). |

## Building

Everything derived from the game (the dumped SWF, decompiled scripts, build output) lives in a work directory
outside the repository: `$EID_FLASH_WORK`, default `~/flash-isaac-decomp`. **Never commit those files.** They
contain the game's code and assets.

Developer requirements (players only need Python): Windows, Python 3 with Pillow, and the following in
`<work>/tools` (or set `$JAVA` / `$FFDEC_JAR`):

- a Java 21 runtime, e.g. [Temurin 21 JRE zip](https://adoptium.net/) unpacked to `<work>/tools/jre/`
- [JPEXS FFDec](https://github.com/jindrapetrik/jpexs-decompiler/releases) zip unpacked to `<work>/tools/ffdec/`
  (tested with 26.3.0, sha256 `35f4930e…645ecd`)
- Adobe's Flash Player 32 projector, `https://fpdownload.macromedia.com/pub/flashplayer/updaters/32/flashplayer_32_sa.exe`
  (signed by Adobe Inc., sha256 `a4b333ac…6066f0`)

```sh
python flash/tools/swfdump.py            # once: launches a copy of the game briefly and writes <work>/isaac.swf
python flash/tools/build.py              # refreshes patcher/eid_flash_payload.json -> <work>/build/isaac_eid.swf
python flash/tools/build.py --debug      # -> <work>/build/isaac_eid_debug.swf (test hooks, payload not refreshed)
python flash/tools/package.py            # -> <work>/build/EID_Flash_<version>.zip (patcher + payload + README)
python flash/tools/build_exe.py          # -> <work>/build/exe/EID_Flash_Patcher.exe (pip install pyinstaller)
```

Release: bump `VERSION`, run `build.py`, `package.py` and `build_exe.py`, commit the refreshed payload, then attach
the exe and the zip to a GitHub release tagged `v<VERSION>`.

Then open the built SWF with `flashplayer_32_sa.exe`. F2 toggles the overlay. Decompiling the game (FFDec
`-export script`) is only needed for research; the build never recompiles game code.

Notes:

- If the game's exe has the "Run as administrator" compatibility flag (common for this game), only processes
  running elevated can read the original. The patcher avoids this by launching a copy from a temporary folder.
- Saves are shared with the Steam version. The game stores everything (stats, unlocks in `so.data.lock`, settings)
  in `SharedObject.getLocal("so", "/")`; the `"/"` path makes it one file for every local Flash player
  (`%APPDATA%\Macromedia\Flash Player\#SharedObjects\<id>\localhost\so.sol`), used by both Zinc's built-in player
  and the standalone projector. Running both at once can lose progress (each writes its in-memory copy back).
- `serial.txt` in the game folder is the Steam version's backup of the save, written and read through Zinc's
  `mdm.FileSystem` (`aloc` / `aloc2`). The modded game can't update it; the Steam version rewrites it from the
  shared save on its next run, and only merges unlocks from it (never removes any).
- Steam achievements go through Zinc (`callit` → `mdm.Process.create` → `FlashAchievements.exe`), so they don't fire
  in the modded game. The Steam version sends all unlocked achievements on every startup, so they are granted the
  next time the normal game is started.

## Description data

Effects are paraphrased from [The Binding of Isaac Wiki](https://bindingofisaac.fandom.com/) (the Flash-era wiki,
CC BY-SA 3.0). Stat values were checked against the game's own formulas in the decompiled game script (sprite 6765).
Where the two disagree, the game's values are used:

- **Damage** (`dmgdo`): `3.5 * sqrt(1 + 1.2 * units)`. Polyphemus adds +6.6 afterwards; Sacred Heart is x1.3 then +4;
  Technology 2 is x0.65; Odd Mushroom (Thin) is units x0.95 - 0.4. There is no x1.5 multiplier for Max's Head or
  Magic Mushroom in this version.
- **Tears** (`firr`): Number One +1.5; Sad Onion, Wire Coat Hanger and The Pact +0.7; Odd Mushroom (Thin) +1.7;
  Wiggle Worm and Squeezy +0.4; Sacred Heart -0.92. Inner Eye, Polyphemus, Ipecac and Mutant Spider all set
  fire delay to x2.1 + 3.
- **Speed**: the total of all speed bonuses is capped at +1. Brimstone, Sacred Heart, The Small Rock and Bucket of
  Lard each give -0.2.
- **Range**: stored in internal units that don't map onto the wiki's numbers, so descriptions say "Range up".
  Roid Rage, Mom's Contacts and SMB Super Fan do give range.
- **Shot speed**: Raw Liver, Mutant Spider, Spirit of the Night and Polyphemus -17%; The Wafer and Mom's
  Contacts -25%.
- **Wiki ID errors**: the wiki lists Blood of the Martyr as 8 (it is 7) and Robo-Baby as 96 (it is 95).
  Item IDs 43 and 61 are unused.

### Trinkets, cards and pills

All three are pickups with entity type `s == 5`. On the floor they use sprite frame 7; in a shop they use frame 15
with sub-frame 3 or 7. The kind is stored in `.col`:

- **Trinkets**: `col` 29-62. These values are the same as EID's trinket IDs; 47 is The Polaroid and 62 is Game Squid.
- **Cards**: `col` 7-28 (tarot) and 70-74 (2 of Spades/Clubs/Hearts/Diamonds, Joker). They are mapped to EID's card
  IDs in `item_data.lua`.
- **Pills**: `col` 1-6 is the pill color. A color only gets an effect (`_root.piller[col]`) when the first pill of
  that color is taken. Until then the overlay shows "Unidentified Pill", as EID does. A fractional value (e.g.
  9.2) selects the good variant (Tears Up rather than Tears Down), and so do Lucky Foot and PHD.

The game's code (the card handler on Q, `pillc`, `piller` and the `trixx()` checks) differs from the wiki in places:

- The Devil card gives +0.75 damage units. Strength gives the Magic Mushroom effect. The Empress applies the
  Whore of Babylon effect at strength 1.5 (+3.4 damage, +0.45 speed). Death deals 60 damage. The High Priestess hits
  the enemy with the most health.
- A Missing Page triggers 5% of the time when Isaac is hit. Game Squid gives +1 damage and a 10% chance of slowing
  tears. Mom's Pearl and Red Patch have no wiki page; their effects come from the code. The Book of Belial gives
  +0.75 damage units, not +2.
- Pill amounts: Tears Up +0.35 / Down -0.28, Speed Up +0.3 / Down -0.24, Shot Speed Up +23% / Down -32%.
  Health is counted in whole hearts.

The Flash game has no item qualities or transformations, so those header elements are not shown.
Stat icons are the AB+ variants, as EID uses them on Afterbirth+.
